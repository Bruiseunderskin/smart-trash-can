# Other 真實相片

讀者：模型與資料人員。何時讀：核對 `other` 類真實相片數目或來源前。

呢個目錄有 155 張 `other` 類真實相片：

- 18 張來自專案自有 `data/field-captures`。
- 137 張來自 TrashNet 的 `trash` 類，授權為 MIT。

檔案名以 `capture_` 開頭代表專案實拍，`trashnet_` 開頭代表 TrashNet。逐張來源與 hash 見 [`../real-photos.csv`](../real-photos.csv)；授權及使用限制見 [`../../DATA-LICENSES.md`](../../DATA-LICENSES.md)。
