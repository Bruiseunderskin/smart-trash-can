# A0 概念圖 — 內容簡報與生成用 Prompt

2026-11-05。用途：CTEA 2026 香港區賽（高級組）A0 展板／概念圖。
本檔的 §2 可直接貼去任何支援長 prompt 的圖像模型或排版工具。

---

## 1. 我們實際會做的東西（一頁清單）

### 1.1 產品

一台四桶 AI 垃圾分類學習機：玩家揀一張印有垃圾的卡 → 相機掃描 → 系統判定四類之一 → 四蓋全開 → 玩家投入其中一桶 → ToF 偵測入咗邊個 → 學習頁對答案 → 計分。

- 一局：**3 分鐘 / 5 回合 / 25–30 張卡**
- 四類：可回收物、廚餘、有害垃圾、其他垃圾

### 1.2 硬件

| 部位 | 內容 |
|---|---|
| 眼＋腦 | ESP32-S31-Korvo-1：SC101IOT 相機、4.3″ 800×480 屏、ES8389 音頻、Wi-Fi |
| 手＋感覺 | ESP32-S3-DevKitC-1：PCA9685（4 舵機）＋ TCA9548A（4 × TOF050C） |
| 板間 | ESP-NOW，協議 v1（seq／冪等／重同步） |
| 電源 | 舵機獨立 5V/3A，每顆 470 µF，四蓋錯開 80–120 ms |
| 相機 | **只在掃卡時開**：連拍 5 幀（間隔 50 ms）→ 關 |

### 1.3 AI

- 輸入 160×160 RGB，中心裁切方形，不用 letterbox
- int8 量化，裝置推理 p50 83.8 ms / p95 83.9 ms
- 5 幀逐幀推論 → 平均 softmax → argmax；`conf < 0.55` → abstain 並重掃一次
- 每回合寫 CSV，記錄逐幀結果與幀間一致率（報告證據）

### 1.4 遊戲流程（畫這條就好）

```
揀卡 → 掃描（5 幀）→ 顯示類別 → 四蓋全開 → 投放 → ToF 偵測桶位 → 學習頁 → 計分
```

### 1.5 軟件結構

- 模式閘：GAME / CHAT 互斥，回合中禁止進聊天，GAME 期間零雲端連線
- 語音：遊戲台詞用 14 段預錄拼接（20 種句子，<50 ms、離線）；評審問答才開小智原生語音
- 五個契約：`stc_mode` / `stc_game` / `stc_vision` / `stc_voice` / `stc_bin`，UI 可整塊替換

### 1.6 現場要交的

1. 實機 demo（可連續跑 5 回合）
2. A0 展板（本圖）
3. 5 分鐘影片
4. 報告：confusion matrix、per-class F1、裝置延遲、量化前後差異、5 幀聚合效果

## 2. A0 概念圖 Prompt（可直接複製）

```
設計一張 A0 直度概念圖（841 × 1189 mm，300 dpi），主題係「智分桶 EDU — AI 垃圾分類學習機」，
用於香港 CTEA 2026 高級組展板。觀眾係評審與中學生，需要 3 米外睇得清標題、1 米內讀得完細節。

【整體風格】
- 技術製圖感：扁平向量、細線條、直角、大量留白，不要 3D 擬真、不要霓虹漸變、不要 AI 藝術感
- 配色只用四色加中性灰：可回收物 #1F6FB2、廚餘 #C8791E、有害垃圾 #B3261E、其他垃圾 #4A4A4A；
  背景 #F7F5F1，線與字 #1A1A1A
- 繁體中文為主，英文只用在 IC 型號與技術名詞（ESP32-S31、TOF050C、int8）
- 不要 emoji、不要圖庫人物照片、不要水印、不要假 logo
- 所有尺寸標註要用真實比例感（4 個桶並排佔畫面下方三分之一）

【版面由上而下分六帶】

1. 標題帶（高 12%）
   主標：智分桶 EDU
   副標：AI 垃圾分類學習機 ｜ CTEA 2026 香港區賽・高級組
   右側小字：一局 3 分鐘・5 回合・25–30 張卡

2. 主視覺（高 30%）
   中央畫系統剖面：左邊「眼＋腦」方塊寫 ESP32-S31-Korvo-1（SC101IOT 相機、4.3 吋屏、音頻），
   右邊「手＋感覺」方塊寫 ESP32-S3（PCA9685 舵機驅動、TCA9548A ＋ 4 × TOF050C），
   兩者之間畫一條虛線箭頭標 ESP-NOW。
   下方接四個並排的桶，每個桶頂有蓋與舵機圖示，桶身標四個類別名與對應顏色。
   桶口各畫一個 ToF 感測器的小圖示與量測光束。

3. 玩家流程帶（高 14%，橫向 ribbon）
   七個節點由左至右，每個節點一個小圖示＋四字標籤：
   揀卡 → 掃描 → 顯示類別 → 四蓋全開 → 投放 → 偵測桶位 → 學習頁
   節點下方一行註：掃描時連拍 5 幀（間隔 50 ms），掃完即關相機

4. AI 管線帶（高 16%，左半）＋ 學習頁示意（右半）
   左：SC101IOT 擷取 → 中心裁切 160×160 → int8 模型 → 5 幀平均 → 四類輸出 → 置信度低於 0.55 則重掃
   右：一個學習頁框，內容示範
       「你掃到：可回收物 (0.87)」「你放咗落：廚餘桶」「正確答案：可回收物桶」
       「本回合 −5　累計 25」「小知識：可回收物包括膠樽、鋁罐、紙皮、金屬罐。」

5. 證據帶（高 12%）
   四張小卡片並排，每張一個標題＋一個大數字＋一行說明，數字先用佔位符：
   「模型準確率 {{ACC}}%」「每類 F1 {{F1}}」「裝置推理 p95 {{P95}} ms」「5 幀一致率 {{AGR}}%」
   卡片下方一行小字：所有數字附原始 log 與測試集，可即場查核

6. 底部帶（高 8%）
   左：軟件結構一句（五個契約模組、模式閘 GAME／CHAT 互斥、GAME 期間零雲端）
   中：里程碑小條（11/09 模型 v1 ・ 11/12 端到端 ・ 11/14 素材初稿）
   右：隊名與年份

【硬性要求】
- 畫面任何一處都不得出現我未提供的數字或獎項；未定的用 {{ }} 佔位符
- 不要畫實際兒童或人臉
- 線條粗細分三級：外框 2 pt、區塊分隔 1 pt、註解 0.5 pt；最小字級 12 pt（A0 上約 4 mm）
- 輸出：向量風格、可印刷、四邊留 15 mm 出血安全區
```

## 3. 使用注意

- 圖像模型對繁體中文字形不穩，**文字最終應在排版軟件重排**；此圖用作版面與視覺方向
- 數字一律留佔位，等 P2 模型與 #26 ToF 有結果再填，避免出現無法查核的數字
- 若模型把「學習頁」畫成手機介面，要明確要求「4.3 吋板載屏、橫向、無邊框手機造型」
