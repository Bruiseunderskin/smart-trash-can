## 接線核對

按 issue 目標拓撲核對：S31 USB host → S3 CDC device；S3 I²C GPIO8/9 → PCA9685 `0x40`、TCA9548A `0x70`；mux CH0–3 各接一個 `0x29` ToF；GPIO19/20 留給 USB。實物板的 pin、電壓、上拉、PSRAM 衝突及 USB 角色需依實際板資料核對。舵機獨立 5 V 供電、共地；先檢查反灌與電源時序。issue 電流估算不代表量測結論。
