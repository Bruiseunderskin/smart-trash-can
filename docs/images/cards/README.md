# 分類卡樣板圖（6×6 cm）

兩套樣板共用同一個版面：60×60 mm、圓角 4 mm、物件區在上 62%、名稱區在下 38%、卡面不印類別。
原圖為 709×709 px @300 dpi（2 mm 出血、4 mm 安全邊）。

| `set-a/` | Set A 單張（12 個 PNG） |
| `set-b-photo-sheet.png` | Set B 拼版（封面 + 10 個物件 + 卡背） |

## 加框版（padding）

教學組要求卡片要有留白，不要整張卡「全白」。`set-a-padded/` 與 `set-b-padded/` 按參考圖的幾何重排：

| 項目 | 數值（卡寬比例） | 709 px 時 |
|---|---|---|
| 外圍透明邊（出血） | 2.5% | 18 px |
| 綠色外框 | 9.5% | 67 px |
| 框內白色留白 | 3.0% | 21 px |
| 外圓角 | 13.0% | 92 px |
| 內圓角 | 8.0% | 57 px |

外框色 `#3F7F4F`。原卡內容等比縮入內框，文字與插畫完整保留。由 `tools/apply_card_padding.py` 產生，可重跑。

## 授權

Set B 全部為開放授權實拍照片（Wikimedia Commons CC BY-SA／公有領域），逐張見 `credits.md`。
卡背必須印出 credit 一行。Set A 為生成插畫，無第三方授權負擔。

## 限制

- Set B 經邊緣去背，部分邊緣仍見殘影；印刷前需換高解像原圖或重新去背。
- 香蕉皮與慳電膽未達沙龍照水平，可換。
- 卡面不採取 QR、ArUco 或條碼，否則「鏡頭辨識」示範失去意義。
