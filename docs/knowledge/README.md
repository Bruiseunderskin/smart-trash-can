# 小智知識庫

此資料夾保存小智回答「智分桶」及香港環保問題的文字資料。建議在小智後台建立以下兩個獨立知識庫，再分別上載對應文件；截圖只顯示名稱和描述欄位，實際支援的檔案格式、標籤功能和匯入方式須以後台為準。本資料夾不代表已完成上載、索引或語音測試。

## 1. 智分桶：產品與遊戲玩法

**知識庫名稱**

```text
智分桶｜產品介紹與遊戲玩法
```

**知識庫描述**

```text
介紹智分桶的目的、遊戲流程、卡片分類與互動方式，供小智以簡單粵語回答玩家及評審的問題。遊戲設計與實際功能以完成整合和實機測試為準。
```

**上載文件：** [xiaozhi-game.md](xiaozhi-game.md)

**建議搜尋標籤／關鍵詞：** `智分桶`、`遊戲玩法`、`卡片分類`、`兒童教育`、`小智`

## 使用及範圍

- 如後台提供標籤功能，可採用上述關鍵詞；若沒有，不需要把它們輸入名稱或描述欄。
- 回答時要區分遊戲答案與現實回收規則；例如發泡膠盒在遊戲歸「其他」，但符合要求的家居發泡膠可交「綠在區區」。
- 兩份資料含官方連結和核對日期；回收安排可能改變，實際投放應查看最新官方指引。
- GitHub issue／PR 工作分類沿用專案 [標籤規範](../labels.md)，與後台搜尋關鍵詞是兩回事。
