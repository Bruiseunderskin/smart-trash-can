# 指定卡片及實物混合模型：實驗記錄

讀者：模型開發及 S31 整合人員。何時讀：審核混合資料訓練、int8 主機評估與未完成項目時。**實驗結果，尚不可作現場交付或自動開蓋。**

> 2026-11-09 資料整理：部分原資料現已封存在 [資料目錄](../../../data/mixed-card-object-archive/README.md)；仍有 1,117 張實物訓練圖缺失，不能完整重建。

## 資料及方法

四類固定映射：`food`→廚餘、`hazardous`→有害、`other`→其他、`recyclable`→可回收。未知是拒絕狀態，不是 `other`。

在使用者明確要求下，本次只作混合資料實驗：訓練使用 1,217 張實物圖及 8,360 張指定卡模擬圖；開發驗證使用 292 張實物圖及 1,900 張指定卡模擬圖。卡模擬數據只用於實驗，任何模擬卡數字都不代表實物表現。`input-manifest.csv` 紀錄每張圖片的 split、來源類型及 hash；原始資料與 source-card manifest 未隨 PR 公開。

38 張卡身份同時存在於卡片訓練和驗證；實物訓練和驗證也同源，不能證明物件或場景完全獨立。RealWaste 包含在訓練時，其來源與 field-probe 相同，因此不能宣稱 field-probe 是獨立來源域。field-probe 及既有現場照片沒有用於訓練、量化校準、閾值或選模。

預訓練起點是既有物件 v2 YOLO11n-cls，160×160，5 epochs，batch 32，Apple MPS；`training-args.yaml` 和 `training-results.csv` 是訓練記錄。int8 以 200 張訓練圖校準，四類每類 50 張，實物／模擬各佔一半。使用 [ESP-DL 量化工具](../../../tools/quantize_espdl.py) 的 S31 `w8a8`，以 ESP-PPQ CPU 模擬評估。

## 主機結果

- S31 目標 int8、292 張同源實物開發圖：240/292（82.19%），macro-F1 0.8203；見 [逐類矩陣](physical-int8-host.json)。
- S31 目標 int8、1,900 張合成卡開發圖：1,900/1,900，macro-F1 1.0；**同一批卡面身份同時出現在訓練，這只是合成指定卡情境，不代表實體卡表現**。見 [矩陣](card-int8-host.json)。
- 原實物 v2 S31 目標 int8、同一 292 張開發圖的主機模擬為 252/292（86.30%），macro-F1 0.8621；此對照的訓練及量化校準不完全相同。混合模型在這批圖上少判對 12 張，不應視為實物能力改善。
- 限定探索：原設定參考門檻 0.55 下，1 張真實空鏡頭被拒絕；數碼封面及卡背則高信心誤判為有害。這三張用於事後觀察，未用來調整模型或門檻，且不代表完整未知物件拒絕率。見 [逐圖結果](unknown-int8-host.json)。

模型位於 `models/mixed-card-object/mixed_s31.espdl`，輸出次序 `food, hazardous, other, recyclable`，須依 `labels.txt` 名稱映射，不可假設沿用舊順序。
