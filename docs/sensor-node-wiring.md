# 感測／舵機節點：有線（USB CDC）接法與協定

狀態：**設計稿（待實作）**，2026-11-04。作者：阿吉 the hermes（代 W Ed / sillysben）。
關聯文件：`docs/s31-gpio-budget.md`（為何需要節點）、`docs/lid-detect-research.md`（感測器選型）、`docs/ROADMAP.md`（plan C）。

---

## 0. 決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 節點 ↔ S31 連線 | **USB CDC（有線）** | demo latency 可預期、無頻道問題、一條線供電＋數據 |
| 節點板 | **Seeed XIAO ESP32-C5** | 已有；原生 USB-Serial/JTAG；11 GPIO |
| 舵機驅動 | **PCA9685**（16 路 12-bit PWM，I²C） | 硬件波形、無 jitter、唔食 CPU |
| 蓋位輸入 | **TCA9555**（16 位 I²C，帶 INT） | 上拉強、支援中斷、螺絲端子免焊 |
| 桶口測距 | **VL53L0X ×4 ＋ TCA9548A 多工器** | 同一支模組兼做「有物掉落」與「料面高度」；4 支同址靠多工器解決 |
| 無線備選 | ESP-NOW（同一份 firmware，config flag 切換） | 協定與傳輸層解耦，換傳輸不改邏輯 |

S31 側不需要任何 GPIO：只用它的 USB-A Host 口。

## 1. 拓撲

```
        ┌──────────────┐   USB-A Host (5V, 500 mA)   ┌────────────────────┐
        │ S31-Korvo-1  │────────────────────────────▶│ XIAO ESP32-C5      │
        │ 眼＋腦       │      CDC-ACM 16-byte frames  │ 節點 (手＋感覺)     │
        └──────────────┘◀────────────────────────────└─────────┬──────────┘
                                                                 │ I²C 3V3/GND/SDA/SCL
                                                    ┌────────────┴────────────┐
                                              ┌─────▼─────┐            ┌──────▼─────┐
                                              │ PCA9685   │            │ TCA9555    │
                                              │ 4× 舵機   │            │ 4× 磁簧    │
                                              └─────┬─────┘            └────────────┘
                                                    │ V+ (獨立 5V 3A)
                                              ┌─────▼─────┐      ┌───────────────────────┐
```

**共地**：S31、XIAO、5V PSU 三者 GND 必須連通。舵機電源只由 PSU 出，不經 USB。

## 2. 引腳分配（XIAO ESP32-C5：11 GPIO，只用 3 條）

| XIAO 腳 | GPIO | 功能 | 接到 | 備註 |
|---|---|---|---|---|
| D4 | GPIO23 | I²C SDA | PCA9685 ＋ TCA9555 ＋ TCA9548A SDA | 同總線並聯 |
| D5 | GPIO24 | I²C SCL | PCA9685 ＋ TCA9555 ＋ TCA9548A SCL | 400 kHz |
| D8 | GPIO8 | INT（輸入） | TCA9555 INT | 低電平有效，上拉 |
| 5V | — | VBUS | S31 USB-A（供電＋數據） | 節點電流約 80–150 mA |
| 3V3 | — | 3V3_OUT | PCA9685 ＋ TCA9555 ＋ TCA9548A VCC ＋ 4× VL53L0X | 邏輯電源 |
| GND | — | GND | 共地 | |

### 2.1 XIAO ESP32-C5 引腳（查 Seeed 官方 KiCad 原理圖 V1.1 確認）

| 腳 | GPIO | 預設功能 | 可用性 | 注意 |
|---|---|---|---|---|
| D0 | GPIO1 | ADC1_CH0 | 可用 | 唯一 ADC 腳（另有 D11/A5 在背面焊盤） |
| D1 | GPIO0 | 一般 IO | 可用 | |
| D2 | GPIO25 | — | 可用（避用） | **strapping 腳**，開機電平影響模式 |
| D3 | GPIO7 | SDIO_DATA1 | 可用（避用） | **strapping 腳** |
| D4 | GPIO23 | SDA | **本方案用** | I²C，模組內建上拉 |
| D5 | GPIO24 | SCL | **本方案用** | I²C |
| D6 | GPIO11 | UART0 TX | **保留** | ROM boot log 會驅動，勿接 push-pull 輸入 |
| D7 | GPIO12 | UART0 RX | **保留** | 救援 console |
| D8 | GPIO8 | SDIO_DATA0 / SCK | **本方案用（INT）** | |
| D9 | GPIO9 | SDIO_CLK / MISO | 可用 | |
| D10 | GPIO10 | SDIO_CMD / MOSI | 可用 | |

USB D+/D− 是 GPIO13/14（在 USB-C 內部，不出現在排針）；JTAG 在背面焊盤。
11 條排針 GPIO 全部列出，本方案只用 3 條，剩 8 條。

I²C 位址：PCA9685 `0x40`、TCA9555 `0x20`、TCA9548A `0x70`、VL53L0X `0x29`（7-bit；datasheet 標 8-bit 寫址 0x52）。

感測器分配：

| TCA9555 bit | 訊號 | 觸發 |
|---|---|---|
| P0–P3 | 桶 0–3 蓋位磁簧 | 蓋關 = LOW，去抖 30–50 ms |
| P4–P7 | 備用（可接超聲、備用磁簧） | — |

TCA9548A 通道（每支 VL53L0X 獨立通道，因此四支都用預設位址）：

| 通道 | 感測器 | 用途 |
|---|---|---|
| CH0 | VL53L0X 桶 0 | 桶口掉落偵測 + 料面高度 |
| CH1 | VL53L0X 桶 1 | 同上 |
| CH2 | VL53L0X 桶 2 | 同上 |
| CH3 | VL53L0X 桶 3 | 同上 |
| CH4–CH7 | 備用 | — |

PCA9685 通道：

| 通道 | 用途 |
|---|---|
| CH0–CH3 | 桶 0–3 蓋舵機 |
| CH4–CH15 | 備用 |

### 2.2 VL53L0X 使用規格（查 ST datasheet DS11555 Rev 6）

| 項目 | 數值 | 對本方案的意義 |
|---|---|---|
| 供電 | 2.6–3.5 V | 3V3 直供（模組自帶穩壓者亦統一餵 3V3） |
| I²C | 最高 400 kHz | 與其他模組同速 |
| 位址 | `0x29`（7-bit）／`0x52`（8-bit 寫址） | 四支同址 → 靠 TCA9548A 分通道 |
| 視場角（FoV） | 25° | 6–12 cm 工作距離 → 光斑直徑約 2.6–5.3 cm，足以覆蓋投擲路徑 |
| 預設時序預算 | 33 ms（量測 30 ms ＋ housekeeping） | 四桶輪詢一輪 ≈ 132 ms |
| 測距能力（室內，33 ms） | 白 88%：典型 200 cm＋／最小 120 cm；灰 17%：典型 80 cm | 本方案只需 6–12 cm，餘量極大 |
| 反射率影響 | datasheet 明示讀數與目標反射率無關 | 印刷卡、深色卡都可讀 |

安裝與判定：

- 每桶桶口上方 **6–12 cm**，垂直向下；桶與桶之間要有隔板，避免互相看到對方光斑（同時讀取也會互相干擾，所以一定要經多工器順序讀）
- 判定：連續 2–3 個樣本距離由基準急跌 **≥ 25 mm** 且維持 ≥ 60 ms → 記 `CARD_PASSED`
- 料面高度 ＝ 穩定後的距離；低於閾值 → `BIN_FULL`（教育賣點，可上畫面）
- 開蓋期間暫停該桶量測（蓋板會擋光路），其他桶照常

失效模式（要寫入報告，不可隱藏）：

- 鏡面／高光澤卡正對角度可能回報「超範圍」→ 用啞面過膠卡可避
- 全黑絨面物料在 >30 cm 會掉檢；本方案 6–12 cm 風險低，但仍要實測
- 強陽光直射會拉低 SNR；室內場地無此問題

## 3. 幀格式（16 bytes，little-endian）

節點 → S31：

```
off  size  field
0    1     magic   = 0xA7
1    1     version = 0x01
2    1     type    (1=LID_OPEN 2=LID_CLOSE 3=CARD_PASSED 4=HEARTBEAT 5=ACK 6=OFFLINE_NOTICE)
3    1     bin_id  (0–3；不相關用 0xFF)
4    4     seq     uint32
8    4     t_us    uint32  節點單調時鐘（µs），事件發生時刻
12   2     arg     uint16  例如舵機角度、延遲回報編號
14   1     flags   bit0=重播(來自緩衝) bit1=低電量 bit2..7 保留
15   1     crc8    poly 0x07，覆蓋 byte 0–14
```

S31 → 節點（type | 0x80）：

| 值 | 指令 | arg |
|---|---|---|
| 0x81 | CMD_OPEN_LID | bin_id，arg = 角度 |
| 0x82 | CMD_CLOSE_LID | bin_id，arg = 角度 |
| 0x83 | CMD_SET_ANGLE | arg = 角度（配合 bin_id） |
| 0x84 | CMD_SESSION | arg = 1 開始／0 結束 |
| 0x85 | CMD_CALIB | arg = 1 進入學習模式 |
| 0x86 | CMD_PING | — |

規則：
- 事件驅動，不輪詢；心跳每 200 ms 一次
- 節點保留 **16 個事件的環形緩衝**；USB 斷線重連後，將未確認事件以 `flags.bit0=1` 重播，保留原始 `t_us`
- 收到 CRC 錯 → 丟棄並計數；S31 連續 5 個錯幀即視為節點故障
- 任何情況 S31 都不得在缺 `CARD_PASSED` 的情況下給分

## 4. 延遲預算（設計目標，**必須實測取代**）

| 環節 | 估算 | 可調？ |
|---|---|---|
| VL53L0X 量測 ＋ 判定（2–3 樣本） | 33–100 ms | 可（改 20 ms 短距模式、或減至 2 樣本） |
| 磁簧去抖 | 30–50 ms | 可（唔影響 demo 觀感） |
| 節點 → USB 送出 | <1 ms | — |
| USB CDC 傳輸（1 ms 幀間隔） | 1–5 ms | — |
| S31 解析 + 狀態機 | <1 ms | — |
| I²C 寫 PCA9685（400 kHz，4 bytes） | ~0.2 ms | — |
| 舵機 0°→90°（MG90S，4.8 V，0.1 s/60°） | ~150 ms | 可（換 6 V 或短行程） |
| 蓋子機械行程 | 50–150 ms | 可（機構設計） |
| **感測 → 蓋開（合計）** | **≈ 230–390 ms** | |

對比 M3 驗收門檻 3 s，餘量約 8 倍。AI 分類 p95 84 ms 另計。

### 4.1 量測方法（不需要兩塊板共用時鐘）

1. **節點自測**：中斷入面記 `t_edge`，寫入 USB 前記 `t_tx`，同一幀內另送 `t_tx` → 得「邊沿→送出」延遲。
2. **S31 自測**：由收到整幀到寫入 I²C 指令的耗時 → 得「主機處理」延遲。
3. **舵機＋機械**：節點記 `t_cmd_recv`（收到 CMD_OPEN_LID）與 `t_reed_release`（同一顆磁簧由 LOW 變 HIGH，即蓋真的離開）→ **同一塊板的同一個時鐘**，量到的是真正端到端機械延遲，無需時鐘同步。
4. 三項相加即完整鏈路；每項各取 50 個樣本，報 p50 / p95，寫入報告。

## 5. 上電與初始化次序（避免舵機抽搐）

1. XIAO 開機 → 先把 PCA9685 `OE` 腳拉高（輸出關閉）
2. I²C 初始化（400 kHz）→ 確認 0x40 與 0x20 有 ACK
3. 由 NVS 讀取四隻蓋的角度 → 寫入 PCA9685（PRE_SCALE = 121 → 50 Hz）
4. 設 `OE` 低（放開輸出）
5. 開始送心跳；等 S31 的 `CMD_SESSION`

若第 2 步任何一個地址無 ACK → 節點進入 `FAULT`，LED 紅快閃，送 `OFFLINE_NOTICE`，**不假裝正常**。

## 6. 失敗處理

| 情境 | 節點 | S31 |
|---|---|---|
| USB 斷線 | 事件入緩衝，持續嘗試重連 | 顯示「感測器未連接」，鎖住計分 |
| 重連 | 重播緩衝事件（`flags.bit0=1`） | 依 `t_us` 排序，過期事件（>5 s）僅記錄不計分 |
| 心跳連續 3 次缺席（600 ms） | — | 標記節點離線，畫面提示 |
| 磁簧與指令不一致（叫開但 2 s 未開） | 送 `OFFLINE_NOTICE`（機構卡住） | 提示「蓋子被卡住」，不計分 |
| ToF 全程無距離跳變但蓋已關 | 仍送 `LID_CLOSE` | 判定「未真正投放」，該回合 0 分 |

## 7. 驗收測試（要交數字）

1. **偵測正確率**：4 桶 × 20 次投放（印刷啞面卡／全黑卡／鏡面卡／皺紙／薄膠袋）→ 逐類列漏檢與誤檢，總漏檢 0、誤檢 0
2. **料面高度**：每桶放入 0／25／50／75／100% 填充物，記錄距離與線性度（R² ≥ 0.95）
3. **抗粗暴**：每桶連續拍蓋 100 次 → 不得產生 false `CARD_PASSED`
4. **斷線韌性**：投放中途拔 USB，5 s 內插回 → 事件不遺失、回合可繼續
5. **延遲**：§4.1 三項各 50 樣本，列出 p50 / p95
6. **連續運行**：30 分鐘不間斷操作 → 無掉幀、無記憶體增長
7. **冷啟動**：上電到可接受指令 ≤ 2 s；期間舵機不得抽動
