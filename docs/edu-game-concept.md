# 智分桶 EDU — 教育遊戲化設計決定（2026-11-03）

狀態：**提案，待拍板**（未實作）。對象：CTEA 2026 第二十屆「創協盃」AI 電子科技創新設計比賽
高級組（港區賽／國際賽）。作者：阿吉 the hermes（代 W Ed 及 sillysben 整理）。

---

## 1. 結論

**貼題：中。** 概念同時命中官方主題《智慧生活－未來設計師》下的兩個方向（智慧教育、智慧環境），
目標用戶與銷售定位（綠在區區學習角、NGO、學校 ICT 科、小型／低成本／可客製）亦直接回答
高級組要求的「對社會貢獻價值」與「可持續發展」。

**但現方案有一個結構問題：AI 可以被繞過。**

現方案寫「detect 邊個桶入」，即靠桶口感應器判定玩家選擇；若評分只依此，AI 全程不參與計分，
玩家看卡片上的圖自己就判得到。評審只需問一句「唔用 AI 都玩得，點解要 AI？」即可穿 25% 的
「應用智能AI科技」。

**決定 D1（必須）**：把 AI 由「可有可無」改成「一定經手」——AI 認物件 → 系統出正解 →
玩家揀桶 → 對錯計分。AI 是出題者與裁判，不是裝飾。此為分工改動，不新增功能。

## 3. 玩法規格 v1

### 3.1 一場流程

```
主頁 ─┬─ [開始遊戲] → 玩法說明 → 開局（3 分鐘倒數）
      └─ [認識四類] → 四類圖鑑 → 各類小百科 → 返回主頁
```

一局：**5 回合，每回合 ≤35 秒**，牌庫當場抽 6 張（見 3.4）。

單回合（每回合必須經過 AI）：

1. 玩家把卡放上掃描位 → 相機拍攝（STC_CAPTURING）
2. AI 分類，顯示預測（STC_CLASSIFYING → 顯示 candidates[2]）
3. 玩家把卡投入其中一個桶 → 桶口感應器回報 (player_bin)
4. 即時判定：預測類別 vs 玩家選擇 → 加分／扣分
5. 不論對錯，顯示正解與一句知識點（STC_LEARNING 版面重用）
6. 回 1，直至 5 回合或時間到

完局 → 總分頁（STC_SUMMARY）：總分、最常判錯的類別、最高分（本機）。

### 3.2 計分（建議）

| 情況 | 分數 |
|---|---|
| AI 預測正確 且 玩家選對 | +10 |
| AI 預測正確 但 玩家選錯 | 0（顯示正解，提示「睇清楚」） |
| AI 預測錯誤（玩家選對） | +10，並顯示「AI 都估錯，你贏咗佢」 |
| 超時／不入桶 | 0 |

第 3 行為本方案的關鍵設計：**AI 認錯時玩家照樣得分**。這使遊戲在模型不準時仍然可玩、
仍然公平，同時讓「AI 不是裝飾」在現場可被觀察到，並且誠實面對域差距（見 `docs/issue12/`）。

### 3.3 卡牌

- 卡面：實物照片 + 物件名稱（繁中 + 英文小字），統一淺色底，方便模型與人眼同時辨識
- 卡背：QR 碼指向 GitHub 上的物件說明（遊戲不使用 QR，單純是教材延伸）
- 卡尺寸：建議 90×130mm（A6 附近），厚身卡紙過膠，實際投入桶口
- 卡池：25–30 張。**不是一局用 25 張**——一局抽 6 張，牌庫用完即重洗

### 3.4 類別比例（按真實棄置比例，不用平均）

| 類別 | 卡數 | 理由 |
|---|---:|---|
| 可回收物 | 10 | 香港家居／校園回收物以紙、膠為主 |
| 其他垃圾 | 8 | 真實佔比最高，教育上最需要澄清 |
| 廚餘 | 4 | 學校午膳剩食為主要來源 |
| 有害垃圾 | 3 | 真實出現頻率低，但概念必須教 |

避免 25/25/25/25：平均比例會在「教育意義」上失真，且容易被評審問「你知唔知真實分類比例」。
此比例本身即為環保意念分的證據，須寫進海報。

### 3.5 卡片 vs 實物（決定 D2 —— **已定：過膠卡片**）

> 2026-11-03 決定：正賽與模型訓練一律用自製過膠卡片；實物只在現場做旁證示範，實物相片**不混入**訓練集。
> 落地注意事項（啞面膠、拍攝條件、背面樣本、域差距答辯準備）見 `docs/lid-detect-research.md` §7。


| | 卡片（正賽） | 實物（旁證） |
|---|---|---|
| 耐用、衛生 | 高 | 低 |
| 詞彙可控 | 高 | 低 |
| 影像域 | 印刷圖卡（與現有 33 張實物相不同域） | 與訓練數據同域 |
| 評審觀感 | 「認得印刷品」質疑 | 示範力強 |

**建議**：卡片做正賽，枱面另擺 3–5 件實物即場掃描，證明相機不只認得印刷圖卡。
若最終決定純卡片，須立即把資料採集由「實物」轉為「印刷卡」，並停止囤實物相。

## 4. 與現有系統的落差（「點樣加」）

現有 UI 狀態機：`ui/lvgl/include/stc_ui.h`

```c
STC_IDLE, STC_CAPTURING, STC_CLASSIFYING, STC_RESULT_OK,
STC_RESULT_RETRY, STC_ERROR, STC_CATEGORY_GUIDE, STC_LEARNING, STC_SUMMARY
```

Payload：`stc_payload_t{state, category_id, confidence, candidates[2], score, streak, lid_open, error_code}`
Actions：`START, HOME, GUIDE, LEARN, FINISH`

**好消息**：單回合流程（拍攝 → 辨識 → 結果）已存在，四類圖鑑、小百科、總分頁已存在，
`score` 與 `streak` 已在 payload 內。所以本方案不是重建，而是**加三個欄位、一個狀態、
一個首頁按鈕**。

| 改動 | 位置 | 工作量（估） |
|---|---|---|
| 首頁加第二顆按鈕（開始遊戲／認識四類） | `generated/stc_layout.c` + `labels.h` + `STC_IDLE` 渲染 | 0.5 日 |
| 放寬圖鑑入口：現時說明書寫「首頁只提供『開始挑戰』」、圖鑑須經完成頁進入；改為主頁直達 | `README.md` 說明 + state transition 驗證 | 0.5 日 |
| payload 加 `round` / `rounds_total` / `time_left_ms` / `player_bin` | `stc_ui.h` + `stc_ui_apply()` 驗證 | 1 日 |
| 新增 `STC_AWAIT_BIN`：等待桶口感應，逾時顯示提示 | 新狀態 + layout | 1–1.5 日 |
| 回合 HUD（第 n/5、倒數、分數條） | `STC_CAPTURING`／`STC_CLASSIFYING` 版面 | 1 日 |
| 結果頁加「AI 對／錯」與得分動畫；沿用 `lid_open` | `STC_RESULT_OK` / `STC_RESULT_RETRY` | 1 日 |
| 總分頁加「最常判錯類別」與最高分（本機儲存） | `STC_SUMMARY` + NVS | 1 日 |
| 四桶燈光與提示音（規則硬要求） | 韌體：4× RGB + buzzer/揚聲器 | 1–1.5 日 |

**硬件新增**：每個桶口一個感應（微動開關或 IR 遮斷），4 個 GPIO 或 1 片 I²C 擴充；
成本約 HK$2–8／個。建議微動開關：卡一定會壓到，結構最簡單、抗光線干擾。

**資料側**：卡片版本需要每個物件的乾淨單張照片（可自行控制光線與構圖），
數量遠少於實物採集，且可分兩批（s6 印卡前、s7 印卡後）。

## 5. 評分估算（阿吉估算，非官方）

假設：模型沿用現有 `cls160-grouped`（公開域 macro-F1 0.865、17 張真實域 probe 0.353），
不重訓；現場有海報、5 分鐘短片、能講出域差距數據。

| 評審項目 | 比重 | 現方案 | D1 修正後 | 主要瓶頸 |
|---|---:|---:|---:|---|
| 創新設計／環保意念 | 25 | 14–17 | 17–20 | 分類遊戲概念本身不新；靠場景與比例設計取分 |
| 製作工藝 | 15 | 8–10 | 10–12 | 四桶機構、卡槽、走線；有無燈光/聲 |
| 人機互動 | 5 | 3.5–4 | 3.5–4 | 觸屏 + 放卡 + 語音，已足夠 |
| 應用智能AI科技 | 25 | 12–15 | 17–19 | **AI 是否必經**、能否講出準確度與域差距 |
| 報告／短片／海報 | 20 | 13–15 | 15–17 | 有 git 證據鏈與真實數據，但須寫得出來 |
| 現場答辯 | 10 | 6–7 | 7–8 | 有數據則強，靠誠實回答域差距 |
| **合計** | **100** | **57–68** | **70–80** | |

解讀：**現方案合格邊緣，D1 修正後才進入有獎區間。** 分數差距幾乎全部來自 25% 的 AI 項
——這也是本項目唯一的真正優勢（有真實評估數據），不應浪費在「AI 只是掃一掃」。

## 6. 三個修正與風險

### D1 AI 必經（最高價值）
- 風險：AI 認錯時玩家照樣得分，可能被質疑「AI 唔準都可以拿分」→ 答辯準備：
  準確度與域差距表（`docs/issue12/field-probe/metrics.md`），並說明「遊戲設計容錯，
  但教育內容永不依賴 AI 猜對」。

### 建議砍三樣
1. **跨機排名** — 需要伺服器與網絡；改本機最高分 + 小獎品。現場 WiFi 不可信。
2. **實時 LLM chatbot** — 離線優先；預錄語音 + 規則式回覆。LLM 是加分項，不做骨幹。
3. **一局 25–30 張卡** — 改為牌庫 25–30 張、每局抽 6 張。

### 必須補（免費分）
- 四桶 RGB + 正確／錯誤提示音（規則原文列出「燈光/聲效果」）
- 海報改 A0 橫度或 120×90（原 A0 直度超 122×90 上限）
- 量度四桶台尺寸 ≤1.5 × 1 × 1.5 m
