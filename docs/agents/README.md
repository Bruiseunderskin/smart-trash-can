# docs/agents — 給 agent 的細節文件

`AGENTS.md` 只放事實與硬規則；這裡放細節。**需要時才讀**，唔需要一次過全部讀完。

| 文件 | 幾時讀 | 讀者 |
|---|---|---|
| [commits.md](commits.md) | 準備 commit、寫 changelog、開 PR 之前 | 任何會 push 的 agent 或人 |
| [skills.md](skills.md) | 開工前想知「用邊個 skill、邊份文件」 | 任何 agent |

## 為什麼分開放

`AGENTS.md` 每次載入都要成本。塞滿細節會令真正重要的規則被淹沒，而細節大部分時間用不著。
所以規則是：**每次都要知的 → `AGENTS.md`；做某件事才要知的 → 這裡**。

新增文件時：在本表加一行，並在 `AGENTS.md` 第 8 節加一句指路。
