## 與 `cards/` 的關係

PDF 內的卡面與 `../cards/` 的 38 張 PNG 相同（已逐張比對 MD5，例如 A-01、B-11 完全一致），所以訓練資料與本試印稿是同一版卡面，不需要重新訓練。

## 印前注意

- 打印時選「實際大小／100%」，先印一頁用尺量度；卡面設定為 60 × 60 mm
- 裁切標記在卡外，圓角要另行修剪
- 卡背為獨立頁；雙面套位與翻轉方向未實測
- PDF 為 RGB 試印稿，沒有印刷廠 CMYK 與出血處理
- 原包說明：B-11、B-14、B-15 為 AI 修整去背，細節可能與原照不同；其餘照片部分保留舊去背殘影，來源與授權未逐張核對
- 新版卡面未在 S31 相機、手持、反光條件下測試
