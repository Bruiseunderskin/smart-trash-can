Set A：9 張 PNG，加共用封面及卡背。
Set B：29 張 PNG，加同一共用封面及卡背。
PDF：兩套 A4 正面拼版及共用背面；裁切標記於卡外，圓角要另行修剪。

每張 PNG 為 709 × 709 像素，附 300 DPI 標記。A4 PDF 每張卡設為 60 × 60 mm。打印時選實際大小／100%，先打印一頁並用尺量度；卡背為獨立頁，雙面套位及翻轉方向未實測。

原始可用卡面為 709 × 709 像素；600 DPI 版本是插值放大，並無增加原始照片細節。PDF 為 RGB 試印稿，沒有印刷廠 CMYK 出血，未實際打印。

B-11、B-14、B-15 以 AI 修整去背，細節可能與原照不同。其餘照片由原先四頁 PDF 復原，部分保留舊去背殘影；來源與授權未逐張核對，公開或大量印製前請確認。新版卡片與 S31 相機、手持、反光及模型識別尚未測試。
