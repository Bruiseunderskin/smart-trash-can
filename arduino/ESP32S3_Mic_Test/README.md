# ESP32-S3 I2S 麦克风录音测试

此示例按 `xiaozhi-esp32` 的 `smart-trash-can` / `bread-compact-wifi` 音频接线编写。
它适用于 INMP441、ICS-43434 等标准数字 I2S 麦克风，不适用于 MAX9814、MAX4466
这类模拟输出麦克风模块。

## 接线

| 麦克风 / 模块 | ESP32-S3 |
| --- | --- |
| VDD / VCC | 3.3V |
| GND | GND |
| WS / LRCK | GPIO4 |
| SCK / BCLK | GPIO5 |
| SD / DATA / DIN | GPIO6 |
| L/R（INMP441） | GND，使用左声道 |

录音回放使用原项目的 I2S 功放接口：

| 功放模块 | ESP32-S3 |
| --- | --- |
| BCLK | GPIO15 |
| LRCK / WS | GPIO16 |
| DIN | GPIO7 |
| VIN | 按功放模块要求供电 |
| GND | GND |

如果不需要板载回放，可将程序顶部的 `ENABLE_PLAYBACK` 改为 `false`。

## Arduino IDE 设置

- 开发板：`ESP32S3 Dev Module`
- Flash Size / PSRAM：按实际模块选择
- USB CDC On Boot：启用（直接使用开发板 USB 口时）
- 串口监视器波特率：`115200`
- ESP32 Arduino 核心：建议 3.x

打开 `ESP32S3_Mic_Test.ino` 编译并上传。首次上电后会自动：

1. 丢弃约 0.2 秒启动数据；
2. 录音 5 秒，串口每 0.25 秒显示实时电平和进度；
3. 输出最小值、最大值、峰峰值、RMS、dBFS 和削波比例；
4. 通过 GPIO7/15/16 回放刚录制的声音。

串口命令：

| 命令 | 功能 |
| --- | --- |
| `r` | 重新录音并回放 |
| `p` | 重放上次录音 |
| `s` | 再次显示上次录音统计 |
| `h` | 显示帮助 |

## 如何判断

- 说话时串口进度条明显变化，回放能听清语音：麦克风基本正常。
- 进度条一直是空的，统计显示“数据几乎不变化”：先检查 VDD、GND、WS、SCK、
  DIN 和焊接；如果均为零，常见原因是 DIN 没接到 GPIO6、麦克风无供电或麦克风损坏。
- 数据在正负满幅之间随机跳动：优先检查 L/R 声道、I2S 格式和时钟线，而不一定是
  麦克风损坏。
- 能检测到声音但回放很小：确认扬声器/功放供电，检查麦克风孔是否被遮挡，也可以
  将 `PLAYBACK_GAIN_Q16` 从 75% 提高到 100%。
- 回放有持续噪声、破音或断续，而音频线焊接正常：可能是个体硬件、电源噪声或振膜
  损伤；换一个已知正常的麦克风做对照最可靠。

电平统计不能发现所有声学缺陷，最终仍应结合回放听感、目视检查麦克风孔和替换法确认。
